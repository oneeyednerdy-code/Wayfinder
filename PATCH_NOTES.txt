NERDSPACE LABS WAYFINDER — ALPHA 0.7.0
Evidence Engine 2

NEW
- Added 7-day, 30-day, and 90-day organic baseline windows for dated CSV analysis.
- Added sustained baseline-shift detection with minimum sample and effect thresholds.
- Added explicit external-influence classes before recommendation generation.
- Added creator-efficiency metrics: followers/hour, engaged viewers/hour, new engaged viewers/hour, chatters/hour, clips/hour, and watch-hours per stream-hour.
- Expanded category roles to Core, Growth, Community, Volatile, Experiment, and Insufficient.
- Added goal priorities for returning audience and engagement depth.
- Added Evidence Engine status: ACTIONABLE or NO ACTION YET.
- Added recommendation refresh guidance: re-evaluate after 45 days or four new qualifying observations.
- Added Evidence Engine 0.7 overview to the Flight Plan with baseline windows, efficiency, and possible baseline shifts.

MODEL RULES
- Confirmed/material external audience influence is classified before organic baselines and recommendations are calculated.
- No recommendation is forced when no claim reaches moderate evidence.
- Change-point signals are associations, not causal claims.
- Revenue remains outside the normalized dataset and intelligence model.
- Twitch CSV remains authoritative for CSV-period performance; Twitch API/EventSub provides supported context; TwitchTracker remains supplemental.

COMPATIBILITY
- Cloudflare Worker + Static Assets architecture retained.
- Existing D1 binding remains WAYFINDER_DB.
- No D1 schema migration required for Alpha 0.7.0.
