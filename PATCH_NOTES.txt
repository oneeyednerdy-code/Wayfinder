NERDSPACE LABS WAYFINDER — ALPHA 0.6.0
Dual-Mode Evidence Engine

ADDED
- Last 30 Days automatic analysis mode for connected Twitch accounts.
- CSV Period mode for specific month/date-range Twitch Analytics exports.
- Source-aware 30-day evidence engine combining supported TwitchTracker aggregate fields with Twitch API/EventSub context.
- Rolling 30-day baseline cards, evidence ledger, flight plan, and guardrails.
- Mode persistence across Twitch OAuth navigation in the same browser tab.
- Dedicated Last 30 Days JSON report export.

DATA RULES
- Twitch CSV remains authoritative whenever a CSV is supplied.
- TwitchTracker may provide the aggregate performance baseline only in automatic Last 30 Days mode.
- TwitchTracker never overrides a Twitch CSV.
- Twitch API VOD data is official broadcast context but does not supply historical per-stream average viewers.
- VOD view counts are never used as live average viewers.
- Current Twitch category is never used as proof of an old stream's category.
- Schedule entries remain planned context only.
- EventSub provides verified observed events where Wayfinder has retained them.
- Aggregate 30-day raid influence is not mathematically removed without first-party analytics granular enough to support that adjustment.

PRIVACY
- CSV revenue/earnings/payout fields remain discarded at import.
- Last 30 Days mode requires no CSV upload.
- Twitch user access and refresh tokens remain transient and are not stored.
